## Scores

| Score | What it measures |
|---|---|
| `q_blur` | Variance of the Laplacian, grayscale, resized to a 512 px short side (`cv2.INTER_AREA`) |
| `q_clip_lo` / `q_clip_hi` | Fraction of pixels ≤ 2 / ≥ 253 on the same resize |
| `q_uiqm` | Underwater Image Quality Measure — UICM + UISM + UIConM, coefficients `0.0282/0.2953/3.5753` (Panetta, Gao & Agaian, *IEEE J. Oceanic Eng.*, 2016) |
| `q_entropy` | Shannon entropy (base 2) of the 256-bin grayscale histogram |
| `q_blank` | `True` if grayscale std < 3, or one grey level covers > 98% of pixels |
| `min_side` / `width` / `height` | Of the original (pre-resize) decoded image |
| `decode_ok` | Whether the bytes decoded as an image at all |

**Reading it**: `noaa-pifsc-bleaching` is entirely 224×224 (confirmed by r0's D9 note) so
every one of its 10,419 images trips `low_res` — this is the dominant contributor to the
corpus-wide 15.0% `low_res` rate. The Roboflow classification/bleaching sources carry the
`clip_high` load (18–24% each): their exports include letterboxed/padded frames whose
solid-colour borders push the clipped-pixel fraction over 0.25. `coralscop-masks-rs`
(54% of the corpus) is the cleanest large source at 6.6% flagged, almost entirely
`clip_high`. `blur_low` is small everywhere (≤ 6.7%) and, because the threshold is a
corpus-relative 1st percentile, always close to 1% of the whole corpus by construction —
it separates the sharpest-vs-least-sharp tail within, not an absolute in-focus bar.

## Reproducing

```
marinedata quality ~/dev/reefsupport/data/_hf/v1/data/images \
  --out ~/dev/reefsupport/data/_quality/v1/quality.parquet --workers 8
```

Re-running with an existing `--out` skips already-scored rows (keyed on
`image_sha256`) and recomputes `flags` for the combined set; two runs over the same
input produce a byte-identical `quality.parquet` regardless of `--workers`
(`tests/test_quality.py`).
