# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The covenant applies in issues, pull requests, discussions and every other space where the project is represented.

## Enforcement

Report unacceptable behaviour to [hello@reef.support](mailto:hello@reef.support). Reports are handled promptly and
treated as confidential. Maintainers apply the enforcement guidelines in the covenant.
